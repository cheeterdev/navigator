# Introducing Cheeter Navigator

![App Preview](image.png)

This is our Browser "Cheeter Navigator", which offers privacy features such as:

- Disposable Mode: When activated, it deletes all of your data after you close the browser.
- Always Incognito: Cookies are never saved except you toggle it per website off.
- Data Manipulation: Opens random Tabs and search queries to hide your real data
+ more!
